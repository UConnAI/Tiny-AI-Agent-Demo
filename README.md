# Mini PDF Agent

This folder is a small standalone demo of a skill-driven AI agent.

Its job is simple:

1. You describe the PDF you want.
2. The app sends your request to an LLM together with one skill, `pdf-generator`.
3. The LLM returns Python code for building the PDF.
4. The app extracts that code and executes it locally.
5. The finished `.pdf` is saved in this same folder.

## What It Is Doing

This mini app is not a normal chat assistant that only answers with text.

Instead, it uses the model to generate executable Python for PDF creation. The runtime then gives that code a limited environment with:

- `output_path`
- `Path`
- `reportlab` helpers such as `SimpleDocTemplate`, `Paragraph`, `Spacer`, `Table`, `TableStyle`, `letter`, `inch`, and `colors`

That means the skill file controls how the model should behave, and the Python app controls how the generated code gets executed.

## Main Files

- `mini_pdf_agent.py`
  The runtime loop. It loads the skill, calls OpenRouter, extracts Python code, executes it, and saves the PDF.

- `skills/pdf-generator/SKILL.md`
  The only skill in this mini app. It tells the model to act like a polished PDF code generator and explains the runtime contract.

- `.env`
  Stores your API key locally.

- `firework.pdf`
  Example output generated by the mini agent.

- `mini_agent.pptx`
  Local presentation file for explaining the mini app. It is ignored by git.

## How the Flow Works

`mini_pdf_agent.py` does these steps:

1. Load `.env`
2. Read the body of `skills/pdf-generator/SKILL.md`
3. Use that skill body as the system prompt
4. Ask you for a PDF instruction and file name
5. Send the prompt to OpenRouter
6. Extract Python code from the model response
7. Execute the code with a small runtime scope
8. Save the resulting PDF in this folder

## Setup

Install dependencies:

```bash
pip install -r requirements.txt
```

Copy `.env.example` to `.env`, then put in your OpenRouter key.

Run the app:

```bash
python mini_pdf_agent.py
```

## Usage

When the app starts:

- type a prompt describing the PDF you want
- type a file name, or press Enter to use `output.pdf`
- type `/exit` to quit

Example prompt:

```text
How do fireworks work?
```

## Important Note

This is a demo architecture.

The app uses `exec()` to run model-generated Python. That makes it flexible and useful for experimentation, but it is not production-safe as-is. A stronger version would add code validation, sandboxing, and retry/repair logic before executing generated code.
